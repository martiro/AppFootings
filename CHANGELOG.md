# Changelog

All notable changes to AppFootings. Versions follow [semver](https://semver.org/):
major for changes to phases, document hierarchy or ID scheme; minor for new aspects, triggers or advisor patterns; patch for wording.

## [1.0.0] - 2026-11-25
### Added
- 11 phases with their deliverables, from Brief to implementation prompts.
- Document hierarchy, cascade-down and discoveries-up rules, alignment report, Project Register with copies table.
- Stable ID scheme and traceability matrix.
- Three complexity levels (Essential, Standard, Complete) with triggers that pull in aspects at any level.
- Advisor mode: next step, prioritisation, decision patterns, critic.
- Mindset: functional analyst with technical judgement, web and mobile product expert, domain expert through web research; depth follows the level.
- Project-grade deliverables rule: every document can be shared with clients, partners and teams as it is.
- Phases at a glance, with a one-line description of each phase.
- Navigable prototype: mock-ups linked along the processes into a clickable preview, with role switching and playable variants.
- Reverse analysis mode for projects already under way: reconnaissance, as-is model with provenance, AS- findings, As-is report, pre-filled phases and change prompts.
- Change procedure with an explicit coherence check before writing, conflicts raised to the user, and "loop until stable" when a discovery flows up during the cascade; animated in the README.
- Recommended way of working: voice for decisions, chat for review, Claude Code for reverse analysis and implementation.
- Install from GitHub: the repository is a plugin marketplace (`.claude-plugin/`), for the Claude apps and Claude Code.
- Hero image explaining the name (deliverables as the footings below ground), also used as the GitHub social preview.
- Worked example (LendLoop) with a clickable prototype, reverse analysis example (FitSlot), generated README images and walkthrough GIF.
